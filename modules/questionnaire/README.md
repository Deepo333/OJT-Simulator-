# `modules/questionnaire` — Stage 2, Step 2

Owner of the questionnaire step. Composes 5 fixed standardized questions
with 10 dynamic questions generated by Claude from the `ResumeProfile` +
`CompetencyMap`, persists as a `Questionnaire` row, presents one at a
time, and collects `QuestionnaireResponse` rows.

## Files

- `standardized-questions.ts` — the 5 fixed questions (source of truth).
- `types.ts` — module-local types.
- `actions.ts` — Server Actions:
  - `ensureQuestionnaire(jobListingId)` — idempotent generator called on
    page load.
  - `submitQuestionnaire(...)` — writes all responses, then hands off to
    Step 3 (assessment) and Step 4 (curriculum) before redirecting.

The DB row is the contract for Step 3.
