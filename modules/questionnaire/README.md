# `modules/questionnaire` — Stage 2, Step 2

Owner of the questionnaire step. All 15 questions are generated by Claude
for this person and this job (`lib/ai/generate-questionnaire.ts`):

- 5 style questions (`LEARNING_STYLE` / `WORK_STYLE`) that deliberately
  cover learning style, tool ramp-up, ambiguity, pace/format, and pressure —
  but phrased around the candidate's actual background and the job's
  actual conditions.
- 10 skill probes (`VERIFY_CLAIMED` / `PROBE_JOB_REQUIREMENT`), each tied
  to a `targetSkill`, anchored to field readiness ("which of these have
  you actually done") rather than adjective self-ratings.

Answer formats: `SINGLE_SELECT` for scales and either/or, `MULTI_SELECT`
where several options can genuinely be true at once (at least 5 of 15).
Every question also offers a free-text escape hatch.

## Files

- `types.ts` — client-facing question + answer shapes.
- `actions.ts` — Server Actions:
  - `ensureQuestionnaire(jobListingId)` — idempotent generator called on
    page load; assigns stable question ids and option values.
  - `submitQuestionnaire(...)` — writes `QuestionnaireResponse` rows
    (`selectedOptions[]` + optional free text), then runs Step 3
    (assessment) and Step 4 (curriculum) and returns the curriculum URL.

The DB rows are the contract for Step 3.
